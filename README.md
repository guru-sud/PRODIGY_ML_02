# Customer Segmentation using K-Means Clustering

## 📌 Project Overview
This project is part of the Prodigy InfoTech Machine Learning Internship (Task-02).  
The goal is to segment customers of a retail store based on their purchase behavior using the K-Means Clustering algorithm.

We use the **Mall Customers Dataset** to group customers based on:
- Annual Income
- Spending Score

---

## 📂 Dataset
Source:  
https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

---

## ⚙️ Technologies Used
- Python 
- Pandas
- Matplotlib
- Scikit-learn

---

##  Algorithm Used
- K-Means Clustering
- Elbow Method (to find optimal number of clusters)
